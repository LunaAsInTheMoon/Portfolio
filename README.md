# Luna Lloyd Portfolio

A lightweight one-page portfolio for Luna Lloyd, a game developer with a BSc in Computer Science specializing in AI and an MSc in Game Development.

This site highlights Luna's self-published games, including Warped, AmazeBalls, and Silvestris, and links out to their itch.io page.

## About the page

- Developer-focused portfolio website
- Dark, experimental visual style inspired by game design and sci-fi UI
- Sections for hero intro, projects/games, and about content
- Built as a static HTML page with no framework dependencies

## Live site

View the portfolio on GitHub Pages: https://lunaasinthemoon.github.io/
